{#- ui/forms.html — form macros on Basecoat 1.1.0 (components/*.css + styles/vega.css). Conventions shared by every ui/ macro (forms, display, readfine): - Arguments are passed by keyword and all have safe defaults, except the few a macro cannot do without (icon_button's label, radio_group's legend), which raise. - Each macro takes `attrs` (a dict, default {}) for anything extra: ids, data-*, hx-*, aria-*. It goes through render_attrs(), which escapes every value and refuses inline event handlers. A "class" in attrs is appended to the macro's own classes instead of replacing them. - No macro emits an on* attribute, a colour literal or hx-swap="none". Forms that live inside an overlay set their own hx-target / hx-swap (design §5.4). - Errors are raised by calling a deliberately undefined name, so the UndefinedError names the rule that was broken (Jinja has no raise statement). -#} {#- render_attrs(attrs={}, skip=[]) — the shared attribute writer. attrs: dict of name -> value. true -> bare attribute; false / none -> left out; anything else -> name="value", escaped. skip: names the caller writes itself (usually ["class"]).
