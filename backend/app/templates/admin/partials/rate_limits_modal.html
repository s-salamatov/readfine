Readfine learns a minimum gap between fetches from what a host advertises: a RateLimit-* budget with requests left in it, or a Retry-After on repeated HTTP 429s. Most hosts advertise nothing, so this table is normally short or empty. Values only tighten automatically; loosening a host again means clearing it here so Readfine re-learns from scratch.

Sites that block automated clients outright (HTTP 403, or a 429 with no timing) do not appear here — there is no rate to learn. Those are tracked per feed instead and show up as {{ badge("throttled", variant="outline") }} in the feed list.
